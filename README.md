# MeshCore mtbeacon — Mesh America catalog

This branch hosts the [Mesh America](https://apps.meshamerica.com) provider catalog
and firmware for **MeshCore mtbeacon** (a MeshCore repeater with a Meshtastic beacon).

- `catalog.json` — the provider catalog (served via raw.githubusercontent.com).
- `firmware/` — the firmware binaries (served via the jsDelivr CDN, which sends CORS).

Firmware source + releases: https://github.com/tek126/MeshCore-mtbeacon
